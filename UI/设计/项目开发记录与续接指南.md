## 一、项目背景

机场**管制室席位交接班检查单** iPad 应用（UI 设计与可交互原型）。
- 使用者：管制室工作人员（塔台/调度席）
- 平台形态：**iPad Pro 竖屏**（3:4 外框，iOS 状态栏）
- 用途：交接班时逐项确认运行模式、设备、场面状况等，并通过**语音语句朗读确认**

## 四、完整开发迭代历史（对话记录摘要）

### v1 初始设计
iPad Pro 竖屏整体框架：状态栏 + 3 界面（席位/检查单/交接班）+ 右侧悬浮框（2 个标签）。

### v2 基础交互
点击席位进入检查单、检查单分组检查项（盲降/天气/跑道/设备/军航/流量/动态）等。

### v3.x · HTML 版核心定型
- **v3.3** 席位界面改为**纯选择器**（不显示在班人员）；悬浮框**不占空间**（真正悬浮，内容可延伸到标签下方）；悬浮框**颜色统一淡色**（不用主/次区分，避免颜色误导当前页）；新增**斜着淡色水印**
- **v3.4** 水印提到**最上层（z-index 60）+ pointer-events:none**（最前但无交互）；**去掉 v2-head**；**页面语义重定义**：检查单 = 检查单模板选择列表（附录 A 跑道 11 项/B 天气 5 项/C 设备 5 项），交接班 = 逐项确认检查项
- **v3.5** 交接班页 v2-head 也去掉；席位点击弹**确认 dialog**（"确认切换本设备为XXX"，确认后**不自动跳转**）；检查单模板改为 **3 列小方框网格**

### v4.x · React 重构 + 交接班页精细打磨
用户要求用 React 重做整个项目 → 创建 `UI/handover-app`。之后是一连串细节修正：

- **v4.1** 标题竖排方向 `vertical-rl` → **`vertical-lr`**（从左到右，非古书式）；设统一最低高度 + grid 居中
- **v4.2** min-height 170→200px、字距 8→4px、字号 14→15px
- **v4.3** 标题改 **flex 居中**（grid 在 vertical-lr 下不可靠）；min-height 260px；**空分类不渲染语音占位文字**
- **v4.4** ⚠️ 紧急修复**页面空白**（Edit 重复插入导致 `const parts` 重复声明 → script 崩溃）
- **v4.5** `.hg` 加 **`flex-shrink:0`** 修复"卡片不能被内容撑开"（flex column 父容器默认压缩子项）；React 版去掉用户误加的 `h-full`
- **v4.6** **删除写死的 min-height**，高度完全由内容撑开（用户明确：不要最低高度）
- **v4.7** **类型标签（单选/多选/确认）不在界面展示**，仅编辑时可见；用 `data-type` 属性承载类型
- **v4.8** **同步用户更新的交接班数据**（天气/空军活动/通航/特殊/动态新增 comp；场面状况数字组改 single）；chip 改 inline-flex
- **v4.9** **inline-flex 加在包裹容器**（.hg-body / "左侧内容"div），不是 chip 本身；HTML 版默认进入交接班页（currentView='handover'）
- **v4.10** **移除"确认无误/不符"按钮**——text 字符串项只渲染为纯标签提示行
- **v4.11** 默认页彻底修复：`view-seats` 的 `active` 类移到 `view-handover`、水印初始文字改"交接班"

## 五、关键设计决策与用户偏好（新 AI 必须遵守）

1. **iPad Pro 竖屏 3:4 外框** + iOS 状态栏（实时时钟）+ Home Indicator；网格底纹背景
2. **3 界面语义**：
   - 席位 = 纯选择器（不显示在班人员）
   - 检查单 = 模板选择（3 列小方框，附录 A/B/C 分组）
   - 交接班 = 当前席位逐项确认（12 个大分类）
3. **悬浮框**：贴边吸附标签条（书签形：一端半圆），**当前界面不显示自己的标签，只显示另外 2 个**；可拖拽到 4 边自动吸附；**所有标签统一淡色**（半透明白+毛玻璃），不要用主/次颜色区分
4. **水印**：淡色斜体大字（96px/800/rgba(15,23,42,.06)/rotate(-18deg)），**z-index 最高 + pointer-events:none**，标识当前页面
5. **席位确认 dialog**：点击席位弹"确认切换本设备为XXX"，确认后**不跳转**，需手动用悬浮框切换
6. **交接班大项卡片**：
   - 标题**竖排在最左**（writing-mode: vertical-lr），**无底色、正常文字颜色**（深灰），右侧虚线分隔
   - **高度由内容撑开，不写死 min-height**（.hg 必须有 flex-shrink:0）
   - 选项：single 单选互斥 / multi 多选叠加 / text 纯标签提示行（**无任何按钮**）
   - **类型标签（单选/多选/确认）只在编辑时可见**，界面只显示选项 chips
   - 语音确认语句：蓝色小字，由各选项组选中项动态拼接（"现在是XXX，XXX"）；**空分类不渲染**
   - **按住语音语句录音**（原型模拟 1.5s 识别）；不相符 → 仅小项琥珀色缓慢闪烁（标题不变色）
7. **数据源**：`交接班页面.js` 由**用户维护**，结构 `{title, comp:[{type, items}]}`；同步时注意类型变化、新增 comp、items 前导空格要 trim
8. **用户会自己改 React 版 UI 交互**——改 React 版前先读文件确认当前状态，避免覆盖用户实验中的改动
