# 管制室席位交接班检查系统 · UI 设计说明（iPad Pro 竖屏 v3）

> 适用项目：e_duty_handbook（机场管制室席位交接班信息确认系统）
> 文档版本：v3.0  iPad Pro 竖屏 / 3 界面 + 2 悬浮框导航
> 编写目的：把现有草图、纸质检查单与 UI 截图统一抽象为可被前端 / 设计工具直接消费的描述，便于其他 AI 生成代码或原型。

## 一、产品定位与核心目标

### 1.1 业务背景
机场管制室需要按席位（西塔台、东塔台、放行、领班、综合协调、航班调度席等）进行 **24 小时轮班交接**。接班一方必须对上一班的运行状态、设备、天气、跑道、军航、流量控制、活动通告等 **逐项确认** 才能完成接班。本系统把传统纸质"管制室机场席位交接班检查单"电子化、可视化、可追溯。

### 1.2 平台与形态
- **运行设备**：iPad Pro，**竖屏固定方向**，不考虑横屏。
- **形态**：原生 App 风格的 SPA，**3 个主界面**（席位 / 检查单 / 交接班）通过 **2 个悬浮框**互相切换。
- **触控优先**：所有可点击元素 ≥ 44pt。

### 1.3 设计目标
1. **一眼可见**——接班人打开 App，所有席位状态、所有待确认项必须一屏可读。
2. **逐项确认**——每条检查项都有显式的"待确认 / 已确认"语义，避免漏项。
3. **极简导航**——悬浮框只显示 2 个（非当前界面），减少认知负担。
4. **可审计**——所有确认动作带人、带时、带席位，便于复盘。

### 1.4 术语表
| 术语 | 含义 |
|---|---|
| 席位 | 管制员值守的工作位（西塔台 / 东塔台 / 放行 / 领班 / 综合协调 / 航班调度席） |
| 主班 / 副班 | 一个席位可以由两个人共同值守，分主、副 |
| 接班 / 退出 | "接班"= 进入席位，"退出"= 交班 |
| 已宣暂 | 已宣读值班术语，准备接班的人员 |
| 盲降 | ILS 仪表着陆系统，19L / 19R / 01L / 01R 即跑道号 |
| RVR | Runway Visual Range，跑道视程 |

### 2.1 整体导航结构
```
App 启动
  │
  ▼
┌────────────────────────────────────────────┐
│ 界面 1 · 席位                              │
│   2 列席位网格，纯选择器                    │
│   右下悬浮框：检查单、交接班（2 个）       │
└────────────────────────────────────────────┘
        │ 点「检查单」悬浮框        │ 点「交接班」悬浮框
        ▼                          ▼
┌──────────────────────────────────┐ ┌─────────────────────────────────┐
│ 界面 2 · 检查单                   │ │ 界面 3 · 交接班                  │
│   检查单模板选择列表              │ │   顶部：席位名 + 进度条          │
│   按附录 A/B/C 分组              │ │   主区：分组检查项（盲降/天气/  │
│   右下悬浮框：席位、交接班       │ │   跑道/设备/军航/流量/动态）     │
└──────────────────────────────────┘ │   右下悬浮框：席位、检查单       │
                                      └─────────────────────────────────┘
```

**核心规则**：3 个界面各对应一个悬浮框；**当前界面不显示自己的悬浮框，只显示另外 2 个**。

**3 个界面语义说明**：
- **席位**：纯选择器，列出所有席位卡，点击进入检查单
- **检查单**：检查单**模板选择列表**，按附录 A 跑道类（11 项）/ B 天气类（5 项）/ C 设备类（5 项）分组；选择某个模板后进入该检查单
- **交接班**：当前席位的**逐项确认检查单**（盲降设备/天气/跑道/设备/军航/流量控制/动态等），每项可标记"已确认/待确认"，并记录操作人时间

**核心规则**：3 个界面各对应一个悬浮框；**当前界面不显示自己的悬浮框，只显示另外 2 个**。

└─ secondary?   // 副班成员

CheckList        // 检查单
├─ groups[]     // 盲降设备 / 天气 / 跑道 / 设备 / 军航 / 流量控制 / 动态

## 四、关键界面与交互

### 4.1 界面 1 · 席位

**布局**
- 顶部直接是席位网格（无大标题）
- 主区：2 列网格，6 张席位卡（西塔台、东塔台、放行、领班、综合协调、航班调度席）
- 每张卡：**纯选择器**——席位图标 + 席位名 + 角色类型（主+副/单岗），不显示在班人员

**交互**
- 点击席位卡 → 弹出**确认 dialog**：
  - 标题："切换席位确认"
  - 内容："确认切换本设备为【席位名 · 角色类型】"
  - 底部说明："确认后不会自动跳转，请手动点击悬浮框进入对应界面"
  - 按钮：[取消] [确认切换]
- 点"确认切换" → 设置 currentSeat，关闭 dialog，**不跳转**（需用户手动用悬浮框切）
- 点"取消" → 关闭 dialog，currentSeat 不变
- 右下悬浮框：检查单、交接班

### 4.2 界面 2 · 检查单（模板选择网格）

**布局**
- 顶部直接是模板分组列表（无 v2-head）
- 主区：3 个分组卡片（附录 A/B/C），每个分组下是 **3 列网格小方框**
  - 附录 A · 跑道类（11 项）：跑道巡视、非全跑道离场、非主用跑道起降、通航保障、校验流程、训练飞行、航班备降返航、鸟情预警、第三方用户、起降间隔、非默认离场
  - 附录 B · 天气类（5 项）：雷雨、大风、降雪除冰、风切变/颠簸、低能见度运行
  - 附录 C · 设备类（5 项）：机场设备故障/降级、内话 RS↔飞坤 切换（2 项）、主备自动化莱斯二所切换（2 项）
- 每项小方框：图标（顶部）+ 模板名（底部，最多 2 行截断）

**交互**
- 点击小方框 → 短暂蓝色高亮反馈（假装选中，实际跳转后续实现）
- 右下悬浮框：席位、交接班

### 4.3 界面 3 · 交接班（竖排标题 + 单选/多选 + 语音确认）

**数据源**：`交接班页面.js`（12 个大分类，每个含 comp 选项组）

**布局**
- 每个大分类一张分组卡片，**标题竖排在最左边**（writing-mode: **vertical-lr**，从左到右，非古书式从右往左）
- 标题**无底色、正常文字颜色**（深灰 #334155），右侧虚线分隔
- **高度不写死，完全由内容撑开**（flex 布局保证竖排标题自然高度完整展示，不被裁剪）；各分类高度随内容/标题长度自然不同，如"动态"2 字卡片矮、"运行模式"选项多卡片高
- 只有大项内部的小项在特殊情况（错误/不相符）才有对应颜色（琥珀色），标题始终正常色
- 分组右侧自上而下排列 comp 选项组：
  - `single` 单选：互斥选择
  - `multi` 多选：可叠加选择
  - `text` 文本项：字符串 → 标签行 + "确认无误/不符"；数字数组 → 数字单选（如跑道道面状况代码 0-5）
- 分组底部一条**蓝色小字语音确认语句**，由各选项组选中项拼接（"现在是XXX，XXX，XXX"）
- **不要"当前项/共几个"数字**，不显示进度

**颜色状态**
| 状态 | 表现 |
|---|---|
| 正常 | 标题深灰正常色；小项文字淡黑色（#1F2937/#4B5563），chip 白底灰边，选中淡蓝底蓝字 |
| 错误/不相符 | **仅小项**文字变**琥珀色**（#B45309）并**缓慢闪烁**（1.6s 透明度 1↔0.4 循环），chip 选中琥珀底；**标题保持正常色** |

**语音确认交互**
- 蓝色小字语句 + "按住录音"提示
- **按住**语句（mousedown/touchstart）→ 录音脉冲动画 + "录音中…松开对比"
- **松开**（mouseup/touchend）→ 模拟识别结果：✓已确认（绿）/ ✗不相符（红）
- 不相符 → 该分组自动标记为错误（琥珀色闪烁）
- 4 秒后恢复初始状态

**分类清单**：运行模式、设备、场面状况、天气、当前进近方式、空军活动、通航、特殊、流量控制、航行通告、动态

**交互**
- 点击单项卡 → 弹出单项确认详情
- 右下悬浮框：席位、检查单

### 4.4 悬浮框组 —— 核心导航（贴边吸附标签条）

**形态**：一个整体容器，里面包含 2 个**标签形按钮**（不是胶囊）。像书签标签一样从屏幕边缘伸出。

**位置**：默认**贴右边缘吸附**（right:0），垂直居中。可拖拽到其他 3 个边缘（左/上/下）自动吸附。

**标签形状**：
- 尺寸：宽 54pt × 高 48pt
- 圆角方向跟随吸附位置：
  - 吸附右边：左半圆右直（border-radius: 24px 0 0 24px）
  - 吸附左边：右半圆左直
  - 吸附顶部：上半圆下直
  - 吸附底部：下半圆上直

**标签内容**：只显示单字标签（如"席位"显示"席位"，"检查单"显示"检查"，"交接班"显示"交接"）。**不显示完整页面名**——页面内容本身已能识别当前界面。

**样式**：**所有标签统一淡色**——半透明白底毛玻璃（rgba(255,255,255,.88) + blur）+ 深灰字。**不用主/次两种颜色**，避免颜色误导用户以为当前在某个页面。hover 时变白底蓝字。

**悬浮特性**：标签 absolute 定位，**不占据布局空间**，真正浮在内容上层；内容可延伸到标签下方，标签遮挡部分内容是可接受的（用户可拖走标签）。

**3 个悬浮框定义**：
| id | 完整标签 | 简写 | 图标 |
|---|---|---|---|
| seats | 席位 | 席位 | ⌂ |
| checklist | 检查单 | 检查 | ✓ |
| handover | 交接班 | 交接 | ⇄ |

**核心规则**：当前界面不显示自己的悬浮框，只显示另外 2 个。

**交互**：
- 点击标签 → 切换到对应界面 + 重新渲染（显示新的 2 个非当前项）
- 拖拽容器空白处（不是按钮）→ 拖动到任意位置
- 松开鼠标 → 自动吸附到最近的屏幕边缘
- hover 阴影向内偏移，强化"伸出边缘"感

### 4.5 页面水印 —— 当前界面标识

**目的**：去掉每页顶部大标题后，用淡色斜体水印标识当前所在界面，不干扰内容。

**样式**：
- 字号 96px，字重 800，字间距 12px
- 颜色：rgba(15,23,42,.06)——极淡，仅作背景标识
- 位置：页面中央，旋转 -18°（斜着）
- **z-index: 60**（最高，在最前面，覆盖在所有内容之上）
- **pointer-events: none**——水印在最前面但**无实际交互作用**，点击穿透到下层内容
- user-select: none（不可选中）

**水印文字映射**：
| 当前界面 | 水印文字 |
|---|---|
| 席位 | 席位选择 |
| 检查单 | 检查单 |
| 交接班 | 交接班 |

切换界面时水印文字自动更新。

### 4.6 单项确认详情弹窗

**布局**
- 顶部：标题 + 附件图标 + 状态徽章 + 关闭按钮
- 预览区：附件图片占位
- 字段区：跑道 / 说明 / 历史
- 备注区：textarea
- 底部：取消 + 已确认

**交互**：点击遮罩或 × 关闭；点击"已确认"更新状态。
