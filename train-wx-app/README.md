# train-wx-app - 模拟机培训/考核微信小程序

模仿原小程序界面与流程的原生微信小程序（无第三方框架、无云开发），当前阶段用本地 Storage 模拟后端数据。

## 在微信开发者工具中运行

1. 打开「微信开发者工具」→ 导入项目，目录选择本文件夹 `train-wx-app`；
2. AppID 使用测试号（游客模式，`project.config.json` 已预置 `touristappid`），或填入自己的 AppID；
3. 编译即可看到工作台页面。

> 若希望通过命令行 `cli.bat open --project ...` 自动调起工具，需先在 工具 → 设置 → 安全设置 → 开启「服务端口」。

## 页面结构与业务流程

```
pages/
├── workbench/       工作台（tabBar 首页）
│   顶部：待办任务 / 已办任务 / 消息提醒 / 反馈记录（前两项红角标、消息提醒 431 效果）
│   搜索框即输即搜；黄色横幅 = 月/年度报告入口
│   待办 tab 底部固定双按钮：模拟机培训/考核（红）· 理论培训（绿）
│
├── simulator-form/  快速填写模拟机培训/考核
│   字段：学员姓名 →（红字提示）→ 模拟机练习号 / 培训分类 / 表单名称 / 资格类型 /
│         扇区 / 天气情况 / 军航活动情况 / 指挥架次 / 复杂程度 / 教员姓名（默认 吴其奇）
│         开始时间（自动预填）/ 培训时长
│   所有选项走底部弹层选择器（取消 / 请选择 / 确认）
│   模拟机练习号 → 跳训练项目选择页；提交 → 生成待办任务
│
├── theory-form/     快速填写理论培训（学员姓名 / 培训主题 / 表单名称 / 开始时间 / 培训时长 / 授课教员）
│
├── task-detail/     待办任务详情
│   编号灰字只读；可编辑字段（学员姓名、培训分类、岗位培训类别、表单名称、扇区、
│   天气、军航、复杂程度）弹层选择后即时回写本地存储；
│   结束时间 / 资格类型 / 教员姓名 灰字只读
│   底部：下一步（蓝）→ 评分页；删除（红，二次确认）
│
├── score/           评分扣分页（下一步后进入）
│   五组扣分项：管制意识和判断力(6) / 方法和程序(6) / 设备操作(4) / 应急处置(3) / 一票否决项(8)
│   每项：名称 | 分值 | 次数 −/＋
│   最后得分 / 预览得分 = 100 − Σ(次数×分值)，最低 0
│   总体情况（必填，占位红字）· 附件（拍照）· 提交（绿，待办转已办）· 上一步（橙）
│
├── training-items/  训练项目选择（模拟机练习号）
│   席位 radio：塔台 / 进近（默认）/ 区域 / 飞服 / 运行
│   全选 / 全取消 / 新增个性化 / 确认；搜索过滤；三个分组折叠单选
│   （复杂情况处置训练 / 专项强化训练 / 不正常情况处置训练），按席位过滤条目
│   确认 → 回填模拟机练习号
│
└── profile/         个人信息（tabBar 第二页：用户卡片 + 月/年度报告入口）
```

## 目录说明

```
├── app.js / app.json / app.wxss   全局入口与配置（tabBar：工作台 + 个人信息）
├── project.config.json            开发者工具配置（touristappid 游客模式可直接编译）
├── utils/
│   ├── store.js                   本地数据存取（待办/已办/消息/反馈 + 编号自增 + 种子数据）
│   ├── dict.js                    数据字典（表单选项、训练项目分组、评分扣分项）
│   └── format.js                  本地时间格式化（YYYY-MM-DD HH:mm:ss，不走 toISOString）
└── components/
    ├── form-cell/                 通用表单行（label + 值/占位 + 箭头，灰字=只读）
    └── picker-sheet/              底部弹层选择器（取消/请选择/确认）
```

## 后续接后端的替换点

所有数据读写都收敛在 `utils/store.js`，接入真实后端时只需把该文件改为 wx.request 调用，页面层零改动；字典数据（`utils/dict.js`）届时同样改为接口下发。
