### 再再后续：改用原生 `<dialog>` + 组件自包含（用户原话「怎么没用 dialog 元素 目前写法 open User 有问题 修改好」）
**先发现的真实 bug**（用户自己改那版里）：`onClick={setUserOpen(true)}` / `onClick={setUserOpen(false)}` ——
不是传函数而是**渲染时立刻调用**，等于每次渲染都 setState → 必然死循环；且 `MainPageLayout` 只传了
`open={open}`，`users`/`currentUser`/`onClose`/`onSwitch` 全丢（列表空、点一下 `onClose is not a function`）。
🔴 **用户把 `src/config/users.js` 删了**（把 `USERS` 内联进了组件）→ 第一次构建报
`Could not resolve "../config/users"`。所以**花名册就留在组件顶部**，别重构回 config。

**改法**（两文件）：
- `SwitchUserDialog.jsx`：**自包含** —— 顶栏入口按钮 + `<dialog>` 弹窗都在组件内；自己读 `app.store` 的
  `currentUser`/`setCurrentUser`；**无 props、无 useState**（开关状态就住 `el.open`）。
  `openDialog()` = `if (el && !el.open) el.showModal()`，`closeDialog()` = `el.close()`；
  点遮罩判 `e.target === e.currentTarget`（::backdrop 没有 DOM 节点，目标就是 dialog 自己）；
  Esc / 焦点锁 / 背景 inert / top-layer 全交给浏览器。卡片样式挂在 `<dialog>` 自己身上。
- `MainPageLayout.jsx`：删掉 `const [open, setUserOpen] = useState(false)`、`currentUser = useAppStore(...)`、
  `UserRound` 图标与整段按钮，就地换成 `<SwitchUserDialog />`；`useState`/`useAppStore` import 一并删。
- ✅ **实测编译出的 CSS**：`.open\:flex[open]{display:flex}`、`.backdrop\:bg-slate-900\/50::backdrop{#0f172a80}`、
  `max-width:calc(100vw - 2rem)`（`calc(100vw_-_2rem)` 的下划线确实转成了空格）、`.h-fit{height:fit-content}`。
  ⚠️ 两个原生坑已写进注释：**已打开再 `showModal()` 会抛错**；**作者 `display` 会盖掉 UA 的 `dialog:not([open]){display:none}`**
  → 必须用 `open:flex`，直接写 `flex` 会让关着的弹窗也显示出来。
- 验证：eslint 0 错；`pnpm run build` ✓ built in 8.49s；`grep "config/users" src/` 无残留。
