# 2026-09-08 工作日志

## e_duty_handbook 语音识别：短词误听导致 0 命中排查

- 现象：用户说"01左"（单独短词）时 checkbox 全不勾，以为后端坏了。
- 诊断：5184 后端已是最新版（/api/corrections、/api/samples 均 200），SenseVoice 正常、文本规则匹配正常。samples.json 7 条样本显示引擎把孤立 "01左" 听成 动腰左/动摇锁/动腰骨/动腰肚/动腰锁（无上下文，ASR 对数字+字母短词识别差），且当时纠错词典为空 → 匹配层 0 命中。
- 处置：
  1. 直接把样本高频误听变体写入纠错词典（server/corrections.json，用户 5184 运行实例即时生效）：动腰左/动摇锁/动腰骨/动腰肚/动腰锁 → 01左；猛将 → 盲降。验证 "动腰左单跑道" 现在命中 单跑道+01L。
  2. admin.js displayResult 改进：引擎原文行总是显示（不再只在替换时才显示）；识别到文字但 0 命中时显示琥珀提示条，指引去纠错词典加词。静态文件即时生效，无需重启。
- 经验：用户测试常单独蹦"01左"式短词，命中差是 ASR 固有弱点，需纠错词典兜底 + UI 明示"识别到了但没命中"；建议引导用户整句说识别率更高。
- 提醒：样本标注"人工校正文本"应填完整正确句子（非勾选项），否则 buildSuggestions 提不出候选。
