## 样本标注功能复用 + 修复"保存后还能再保存"

- 需求：样本标注功能同时在「语音识别」页实现；排查"保存后仍可保存"。
- 诊断：后端 `samples.js#update` 是幂等覆盖（按 id 改 list[idx]，不新增记录），数据无重复问题。真正原因是前端：
  1. 保存成功后未回写本地 `samplesCache`（marked/correctedText 仍为旧值），翻页或刷新后重渲染又显示"待标注"+引擎原文；
  2. 保存按钮 1.5s 后自动复原为可点"保存"，无"已保存"语义 → 看起来像"没保存成功、可以再保存"。
- 修复 + 重构（server/public/index.html、admin.js）：
  1. 样本块改为可复用：HTML 用 `[data-sample-block]` + class 选择器（原 id 全部替换为 class），「语音识别」页与「样本标注」页各一份；JS 用 `renderSamples()`→`renderSampleBlock(block, ctx)` 渲染全部块，两块共用同一 `samplePage`/`samplePageSize`，翻页/每页条数两处同步。
  2. 保存成功后回写 `samplesCache` 中该样本（correctedText/targetChecked/marked/updatedAt）并 `rowTargets` 同步。
  3. 按钮状态：已标注 → 置灰「已保存 ✓」（disabled）；仅当再次修改文本或 chips 才启用为「保存修改」。去掉了原来的 setTimeout 复原逻辑。
- 验证：node --check 通过；旧 id 无残留；HTML 有 2 个 data-sample-block、div 33/33 平衡；curl 5184 返回新页面与脚本。
