  删 `SNAPSHOT_TABLE` 常量与那段注释、删 `latestDayOf()`、`list` 还原成单次查询（`const where` / `const rows`），
  import 收敛回 `import { wallDayWhere } from '../utils/date.js'`。
- 实测（5183 + 5173 代理）：10-06 → 54；10-05 / 10-07 / 10-09 / 10-10 → **0**（响应只剩 `{source,total,items}`，
  无 `dataDate`）；10-04 → 87、09-29 → 128 不变。`node --check` 通过。
- ⚠️ 留给用户的提醒（未动手）：前端 `store/fips.store.js` 里还有 3 处 `dataDate`（state / `fetchFlights` /
