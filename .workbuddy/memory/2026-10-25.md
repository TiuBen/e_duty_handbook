## english/icao 从勾选框改成 radio 单选（用户修正）
- 语义：english = true英文 / false中文；icao = true ICAO4字码 / false IATA3字码。
- **列上没配对应字段（undefined）→ 设置页不渲染这组 radio**（配不配由 config/fipsHeaders.js 决定）。
- store：`toggleColumnFlag` 改名 **`setColumnFlag(view, keyName, flag, value)`**（radio 是设值不是切换）。
- 设置页：COLUMN_FLAGS → **COLUMN_RADIOS**（options [{value,label}]），radio name = `${view}-${keyName}-${flag}`；
  判定渲染用 `typeof h[flag] !== "boolean"`（false 也要渲染）。buildHeaders 的布尔回填本来就兼容 false ✓。

## 🔴 buildHeaders 开关回填修正：config 没配 → 一律删掉
- 现象：config 里 flight_date 删掉 english/icao 后，设置页 radio 还在 —— 因为设置页读的是
  **store 持久化过的表头**（本地存着旧测试时的 english:true），buildHeaders 回填「本地有布尔就覆盖 config」
  把「config 没配」盖掉了。
- 修复：buildHeaders 加 `pickFlag(configCol, saved, flag)` —— config 配了布尔 → 本地布尔优先、
  否则 config 默认；**config 没配（undefined）→ 一律返回 undefined（删掉），本地旧值不算数**。
  config = 唯一事实来源，删字段即关开关，无需清 localStorage。
