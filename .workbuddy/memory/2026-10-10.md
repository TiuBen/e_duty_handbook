## flight-dispatch-system：Editor.jsx 第三列不滚动 → 缺 `min-h-0`
- 现象：`<div className="... flex-1 overflow-y-auto">`（视频列）没有内部滚动，整块被裁。
- 根因：`overflow-y-auto` 只对**高度确定**的元素生效。布局链是
  `ContentLayout(h-[calc(100vh-90px)] flex 行) → 右内容(flex-1 min-h-0 flex-col) → Editor 的行(flex-1)`，
  前三段高度都确定，**唯独这一行没写 `min-h-0`** → flex 项默认 `min-height:auto`，拒绝收缩到内容高度以下，
  行被最长的那列撑高 → 列高 = 内容高 → 没有溢出可滚（内容最终被 ContentLayout 的 `overflow-hidden` 裁掉）。
- 修法：给这行加 `min-h-0`（一行 class 变化）。顺带删掉该文件未使用的 `useEffect, useMemo` 导入（eslint 报的
  2 个 error，与本次无关但同文件顺手清掉），`npx eslint` 现 0 错。
- ★ 记住这条通用规律（已记进 MEMORY.md）：**父链只要有一段高度不确定，`overflow-y-auto` 就全失效**；
  `flex-1` 的**行容器**必须配 `min-h-0`。
- 顺带发现（未改）：① main / aux 两列没有 overflow 处理，内容长了同样会被裁 —— 要滚得自己加
  `min-h-0 overflow-y-auto`；② `templateType.includes(...)` 在 `templateType` 还是 `null`（store 初值）时会抛。
